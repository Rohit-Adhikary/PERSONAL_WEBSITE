## 🌐 How to Host on GitHub Pages (Free, Lifetime Hosting)

### Step 1: Create a GitHub Repository
1. Log in to your [GitHub Account](https://github.com).
2. Click the **+** icon on the top right -> **New repository**.
3. Name your repository (Recommended: `portfolio` or `rohit-portfolio` or `<your-username>.github.io`).
4. Leave it as **Public** and do **NOT** check "Initialize with README" (we already have files).
5. Click **Create repository**.

### Step 2: Push your code to GitHub
Run the following commands in your terminal inside this folder:

```bash
git add .
git commit -m "Initial commit: Rohit Adhikari Portfolio Website"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

### Step 3: Turn on GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (tab on the top right of the repo).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment** -> **Branch**, select `main` branch and folder `/ (root)`.
5. Click **Save**.
6. Wait 1–2 minutes. Your website will be live at:
   `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`
   *(or `https://<YOUR_GITHUB_USERNAME>.github.io` if your repo is named `<YOUR_GITHUB_USERNAME>.github.io`)*

## 🛠️ How to Update Your Personal Links & Info

Open `index.html` in any text editor:
- **Email**: Search for `your-email@example.com` and replace with your actual email.
- **GitHub**: Search for `https://github.com` and replace with your profile URL.
- **LinkedIn**: Search for `https://linkedin.com` and replace with your LinkedIn URL.
- **Codeforces**: Search for `https://codeforces.com` and replace with your profile URL.
- **Kaggle**: Search for `https://kaggle.com` and replace with your Kaggle URL.
- **Add Your Photo**: Place your picture inside the folder (e.g. `assets/photo.jpg`) and link it inside the `.avatar-placeholder` div.
